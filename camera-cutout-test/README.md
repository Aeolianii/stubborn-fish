# 拍照 + AI 抠图独立测试包

这个目录从主项目提取了当前正在使用的完整测试链路：

1. 手机拍照或从相册选择 JPEG、PNG、WebP 图片。
2. 输入目标描述并选择人物、动物、植物或其他。
3. 后端调用 `doubao-seed-2-1-turbo-260628` 获取目标粗轮廓。
4. 浏览器根据粗轮廓、本地颜色和纹理生成透明 Alpha 蒙版。
5. 在透明背景和鱼缸画布中预览结果。

## 环境要求

- Windows 10/11
- Node.js 20 或更高版本
- pnpm 11

建议把整个目录解压到 D 盘，例如 `D:\camera-cutout-test`。依赖会安装在当前项目目录内。

## 启动

压缩包内已包含测试用 `.env`。在 PowerShell 中进入本目录后运行：

```powershell
.\start.ps1
```

也可以手动运行：

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm dev
```

然后在电脑浏览器打开：

```text
http://127.0.0.1:3000/
```

## 手机实机测试

电脑和手机连接同一局域网，然后：

1. 把 `.env` 中的 `HOST` 改为 `0.0.0.0`。
2. 运行 `ipconfig`，找到电脑的局域网 IPv4 地址。
3. 启动服务，在手机浏览器打开 `http://电脑IP:3000/`。
4. 若系统防火墙询问，只允许专用网络访问。

文件选择按钮会调用手机系统的拍照或相册选择界面。不要直接双击 `index.html`，页面必须由本目录中的后端服务提供。

## 常见问题

- `缺少必需环境变量 ARK_API_KEY`：检查 `.env` 是否存在并包含有效 Key。
- `暂时无法连接目标定位服务`：检查网络、模型权限和 API Key。
- 手机打不开：确认 `HOST=0.0.0.0`、手机和电脑在同一局域网，并检查防火墙。
- 图片无法上传：只支持 JPEG、PNG、WebP，单张不超过 5 MB。

`.env` 含测试凭证，仅在可信同学之间传递；测试结束后建议轮换该 Key。
